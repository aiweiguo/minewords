# MineWords Asset Credits

Placeholder pixel-style SVG icons in this project are original placeholders for development.

When replacing with production art, prefer these sources:

## Game-icons.net (CC BY 3.0)

- Website: https://game-icons.net/
- License: Creative Commons Attribution 3.0 Unported (CC BY 3.0)
- Attribution required when using icons from this library

Suggested drop-in paths:

- `public/assets/icons/resources/` — wood, stone, iron, emerald, diamond
- `public/assets/icons/equipment/` — sword, pickaxe, axe, shield
- `public/assets/icons/mobs/` — zombie, creeper-like, skeleton
- `public/assets/icons/ui/` — lock, star, chest

## Kenney (CC0)

- Website: https://kenney.nl/assets
- License: CC0 1.0 Universal (public domain)
- Optional attribution appreciated but not required

Suggested drop-in paths:

- `public/assets/backgrounds/` — forest, cave, village, battle, base
- `public/assets/ui/` — panel, button, inventory-slot

## Notes

- Do **not** use official Minecraft assets or trademarks.
- Keep filenames the same when swapping placeholders for real art so the app continues to work without code changes.
